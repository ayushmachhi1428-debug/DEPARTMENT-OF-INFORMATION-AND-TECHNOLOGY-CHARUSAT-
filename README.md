### Project Overview
A fully responsive, modern web portal designed for the Department of Information Technology at CHARUSAT. The portal showcases the department's vision, academic programs, distinguished faculty members, cutting-edge laboratory facilities, and institutional contact channels.

### Technologies Used
- **HTML5:** Semantic structural markup (`<header>`, `<nav>`, `<section>`, `<footer>`, forms, etc.)
- **CSS3:** 
  - **CSS Flexbox:** Used for navigation bar alignment, responsiveness, and about section layout.
  - **CSS Grid:** Implemented for multi-column grids in Programs, Faculty, Laboratories, and Contact sections.
  - **Media Queries:** Comprehensive responsive breakpoints for desktop (>1000px), tablet (600px - 1000px), and mobile (<600px).
- **Git & GitHub:** Version control tracking and remote repository hosting.
- **GitHub Pages:** Live web hosting and deployment.
